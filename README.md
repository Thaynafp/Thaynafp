## 🚀 Projetos em destaque

### [📦 Análise de E-Commerce — Olist](https://github.com/thayna-data-portfolio/olist-ecommerce-analysis)
Pipeline ETL em Python processando +100 mil pedidos, modelagem dimensional (Star Schema) e dashboard em Power BI com DAX.
**Insight:** correlação negativa (-0,33) entre prazo de entrega e avaliação do cliente — direcionador para decisões de logística.
`Python` `Pandas` `Power BI` `DAX` `Star Schema`

### [🛰️ SpaceRoute Manager — Roteamento Orbital](https://github.com/Thaynafp/space-route)
Sistema de gestão de rotas orbitais com dados reais do Space-Track.org: Dijkstra para roteamento, fila de prioridade (heapq) para alertas de colisão e programação dinâmica para otimização de manobras.
**Insight:** correlação forte (r ≈ -0,95) entre altitude e velocidade orbital, validando o modelo físico com Teorema de Bayes e Lei de Kepler.
`Python` `MySQL` `Dijkstra` `Estatística Bayesiana`

### [📈 CRM para E-Commerce](https://github.com/thayna-data-portfolio/crm-ecommerce)
Modelagem relacional em MySQL (5 tabelas) e dashboard em Streamlit para acompanhamento de KPIs (ROAS, CTR, CPC) e identificação automatizada de leads inativos.
`SQL` `MySQL` `Python` `Streamlit`

### 🗣️ Analisador de Reuniões com NLP
Pipeline de NLP em Python para mais de mil transcrições comerciais — tokenização, TF-IDF e classificação automática de intenção (elogio, reclamação, compra).
`Python` `NLP` `TF-IDF`
